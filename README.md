# Energy Meter Card

A Home Assistant Lovelace card for a mains energy meter (Tuya GR2PWS flashed with ESPHome),
styled to match [eybond-inverter-card](https://github.com/pollstar/ha-eybond-local).

Planned:

- live gauge: current against the main breaker rating, power, voltage, frequency, cos φ
- odometer-style meter reading with day/night tariffs (T1/T2)
- protection and stale-data states (OVP/OCP, no grid, MCU silent)
- statistics dialog with T1/T2 history and a meter-vs-inverter balance check
- en / uk / ru, light / dark / auto theme

Status: work in progress.
